ALFAMED
App de saúde · Flutter + API REST

Aplicativo móvel voltado ao paciente — agendamento de consultas, prontuário, exames e anamnese. É a melhor amostra prática do que sei fazer.

Arquitetura
  • Modular por features
  • Flavors de ambiente (dev/prod)
  • CI/CD com GitHub Actions
  • Camada de serviço com models tolerantes a nulos
Funcionalidades
  • Cadastro, login e sessão
  • Agendamento (unidade → especialidade → vaga)
  • Prontuário com exames
  • Anamnese e perfil do paciente
Desafio que resolvi

O login falhava no APK instalado com 401 Unauthorized. Diagnostiquei que a proteção CSRF do back-end exigia o cabeçalho Origin, ausente nas requisições do cliente HTTP no mobile — e corrigi enviando Origin/Referer nas chamadas de autenticação. Também implementei tratamento de erros por código HTTP (409/410/422) com recarga automática de vagas.
