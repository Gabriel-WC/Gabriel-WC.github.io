## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript puro
- GitHub Pages

O projeto permanece propositalmente sem framework: para uma página institucional estática, HTML, CSS e JavaScript atendem ao problema com menos complexidade e deixam os fundamentos web explícitos.

## Recursos

- Navegação responsiva e menu mobile acessível
- Animações com `IntersectionObserver`
- Suporte a `prefers-reduced-motion`
- Transição Preview ⇄ QR Code nos projetos comerciais
- Links para GitHub, LinkedIn, currículo e demos
- SEO e metadados básicos para compartilhamento
